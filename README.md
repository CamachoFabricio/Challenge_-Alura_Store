# Challenge Alura Store
## Practicando Python para Data Science

Este código muestra el análisis y visualización de datos referente a un problema de una persona que tiene 4 tiendas y quiere vender una tienda en base a los siguientes rubros.

* Análisis de facturación
* Ventas por categoría
* Calificación promedio de la tienda
* Productos más y menos vendidos
* Envío promedio por tienda
